📖 使用说明

能在浏览器打开的版本：苹果提醒事项的用法 + 没做到扣分统计 + 循环重复 + 两个人分别打卡。云端已改用 GitHub：公开仓库放网页、用 GitHub Pages 打开；私有仓库放打卡数据。令牌只需填一次，之后打开页面自动拉取最新数据、改完自动推送同步，不用再手动点。

点圆圈 = 完成，循环事项会自动生成下一次；点「没做到」= 按难度扣分并进入下一次。没点「没做到」的就算当天做到了：循环事项（每天 / 每周 / 指定星期 / 每月 / 每隔 N 天）跨天会自动滚到下一次出现，不扣分，也不会以逾期形式留在「今天」和「全部未完成」里（每天的事项滚到今天时，是今天新一次的，不是昨天的逾期）；少数事项带一天补做宽限：到期当天没做完，第二天仍会留在「今天」里并标上「可补」，这一天里补做了点完成即可，点「没做到」照常扣分并进入下一次；如果这多留的一天也过去了还没点，才按上面的规矩自动滚走算做到，不会无限期挂着；一次性事项（不重复）是真待办，不适用自动滚动，到期没处理完会继续留在「今天」和「全部未完成」里提醒，直到点完成、点「没做到」或改期。难度定分：非常简单 2 分 · 简单 3 分 · 一般 5 分 · 较难 8 分 · 非常难 12 分，可单独改。点每条事项右边的「编辑」，可以改它的标题、归属、日期时间、循环和扣分，也能在编辑区里删除这条（删除要点两次确认）；改完会自动同步到云端。点顶部「我 / 孩子」，页面只显示那个人的卡片和提醒事项，另一个人的完全不出现；选「全部」才同时显示两组卡片。卡片数字只算当前这个人的事项（共用事项两边都算）；点卡片里的「今天 / 计划 / 全部未完成 / 旗标」，列表只看那一类，再点一次同一张卡片回到那个人的全部。全部事项保存在私有数据仓库中：在「说明与同步」页填好一次令牌后，打开页面会自动拉取最新数据，任何改动（打卡、新建、编辑、删除）都会自动推送到云端；另一台设备打开页面、或切回页面时，也会自动拿到最新数据。两台设备同时改了数据也不用担心：同步是合并式的，不会拿一台设备的数据覆盖另一台——扣分、加分、临时扣分记录取两边的合集，一条都不会因为同步被删掉；同一条事项两边都改过时，以最后修改的那一份为准；在一台设备上删掉的事项或记录，也不会被另一台设备的旧数据带回来。每次合并、导入或恢复之前，页面还会自动把替换前的数据在本机存一份备份（在「说明与同步」的同步卡片下方，最多 10 份），万一哪次数据不对，可以从备份里恢复。另外，页面里有家长专用的「给孩子加分」：只有输对密码（密码在页面里自己设置，只保存哈希）才能给孩子加分，加多少分和事由都当场填写并留记录；加分计入孩子分数，孩子分数 = 100 − 累计扣分 + 累计加分，可以超过 100 分。孩子能看到加分记录，但没有密码不能加分、也不能删除加分记录。另外，页面里还有家长专用的「给孩子临时扣分」：家长输密码后可给孩子临时扣分，分值当场定、事由必填，计入孩子累计扣分，与加分共用同一个密码；孩子能看到临时扣分记录，但没有密码不能扣分、也不能删除临时扣分记录。

☁️ GitHub 云端同步

第 1 步 · 公开代码仓库（放网页）：在 GitHub 新建一个 Public 仓库，例如 reminders-web，把本页的 index.html 放进去；再到仓库 Settings → Pages → Source 选 main 分支 / 根目录，保存后得到网址 https://你的用户名.github.io/reminders-web/，你和孩子都收藏这个网址打开。

第 2 步 · 私有数据仓库（放数据）：再新建一个 Private 仓库，例如 reminders-data，什么都不用放 — 第一次点「推送」时网页会自动在里面创建 data.json。

第 3 步 · 令牌：GitHub 头像 → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token：只选私有数据仓库 reminders-data，权限只给 Contents: Read and write。生成后复制令牌（只显示一次）。

第 4 步 · 在下面填好令牌（只需填这一次）：你和孩子在各自设备打开网页，各自填同一数据仓库和各自的令牌。之后全自动：打开页面自动拉取最新数据，打卡、改事项后自动推送；另一台设备打开页面或切回页面就会自动更新，不用再点推送 / 拉取（两个按钮保留作手动兜底）。同步时云端和本机的数据是先合并再写回的，不会互相覆盖，两边各自记的打卡、扣分、加分记录都会保留下来。

状态：填好令牌后自动同步：打开页面自动拉取，改动自动推送。同步是合并式的：云端和本机的数据先合到一起再写回，扣分、加分记录取两边的合集，不会拿一边覆盖另一边；上面两个推送 / 拉取按钮是手动兜底，点的也是同一次合并同步。

两个人怎么用？

顶部切「我 / 孩子」只看各自的事项；新建时选归属。共用事项两个人都要完成，点「没做到」只扣当前所选档案那个人。分数分开算，统计和扣分记录都会写清是谁。

本页在本机浏览器也会留一份，关掉再打开不丢；填好令牌后，跨手机、跨人自动同步（数据在私有仓库的 data.json 里）：打开页面自动拉取，改动自动推送。
