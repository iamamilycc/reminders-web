扣分记录

云端改用 GitHub 了，分工是这样的：
公开代码仓库 → GitHub Pages 打开网页

只放 index.html 网页文件，本身不含任何数据和令牌，谁有网址都能打开页面，但看不到你们的打卡数据。

私有数据仓库 → 只放一个 data.json

全部事项、打卡和扣分记录都存在这里。网页通过 GitHub Contents API 读写这个文件，仓库设为 Private，别人打不开。

令牌用 GitHub 个人访问令牌，只填在各自手机/电脑的这一页里、只保存在各自设备本地，绝不写进代码、绝不上传到公开仓库。我这边没有你的 GitHub 账号和令牌，没法替你直接建仓库或存进去 — 你按下方 4 步建好后，点一次推送就能用。

📖 使用说明

点圆圈 = 完成，循环事项会自动生成下一次；点「没做到」= 按难度扣分并进入下一次。难度定分：非常简单 2 分 · 简单 3 分 · 一般 5 分 · 较难 8 分 · 非常难 12 分，可单独改。点每条事项右边的「编辑」，可以改它的标题、归属、日期时间、循环和扣分，也能在编辑区里删除这条（删除要点两次确认）；改完记得点「推送到 GitHub」同步。点顶部「我 / 孩子」，页面只显示那个人的卡片和提醒事项，另一个人的完全不出现；选「全部」才同时显示两组卡片。卡片数字只算当前这个人的事项（共用事项两边都算）；点卡片里的「今天 / 计划 / 全部未完成 / 旗标」，列表只看那一类，再点一次同一张卡片回到那个人的全部。全部事项保存在私有数据仓库中，打开页面后到「说明与同步」页填好令牌、点「从 GitHub 拉取」即可载入。

☁️ GitHub 云端同步

第 1 步 · 公开代码仓库（放网页）：在 GitHub 新建一个 Public 仓库，例如 reminders-web，把本页的 index.html 放进去；再到仓库 Settings → Pages → Source 选 main 分支 / 根目录，保存后得到网址 https://你的用户名.github.io/reminders-web/，你和孩子都收藏这个网址打开。

第 2 步 · 私有数据仓库（放数据）：再新建一个 Private 仓库，例如 reminders-data，什么都不用放 — 第一次点「推送」时网页会自动在里面创建 data.json。

第 3 步 · 令牌：GitHub 头像 → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token：只选私有数据仓库 reminders-data，权限只给 Contents: Read and write。生成后复制令牌（只显示一次）。

第 4 步 · 在下面填好并推送：你和孩子在各自设备打开网页，各自填同一数据仓库和各自的令牌。改完事项记得点「推送」，另一台先点「拉取」再打卡，避免互相覆盖。

两个人怎么用？

顶部切「我 / 孩子」只看各自的事项；新建时选归属。共用事项两个人都要完成，点「没做到」只扣当前所选档案那个人。分数分开算，统计和扣分记录都会写清是谁。

本页在本机浏览器也会留一份，关掉再打开不丢；跨手机、跨人同步靠本页的 GitHub 推送 / 拉取（数据在私有仓库的 data.json 里）。
